Grace AI / operator setup

Create an encryption key

This page creates a random key in your browser. It does not send the key to Grace AI or store it. Keep it private; do not paste it into chat.

Use a new key only for initial setup. Replacing a working key after adding administrators or provider keys makes those stored secrets unreadable unless they are migrated.

  1. Generate the key and copy it. Keep a secure backup.
  2. In Vercel, open your graceorg project and go to Settings → Environment Variables.
  3. Edit GRACE_ENCRYPTION_KEY for Production. Paste the key only—without quotes or spaces—and save.
  4. Tell your operator that it is saved. A redeploy is required before setup can continue.

The generated value is 44 characters and ends with =. Never share it in a message or screenshot.
